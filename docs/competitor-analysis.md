# Competitor Analysis — Uptime Monitoring Platforms

## Target Market Gaps

### 1. Beautiful + Affordable
Better Stack is beautiful but expensive ($24/mo+). UptimeRobot is affordable but ugly. Nobody owns "beautiful AND cheap."

### 2. Affordable Incident Management
Better Stack does it but starts at $24/mo. A $9/mo plan with basic on-call would steal users.

## Key Competitors

| Competitor | Free Tier | Paid Start | Strength | Weakness |
|---|---|---|---|---|
| UptimeRobot | 50 monitors/5min | $7/mo | Brand, free tier | Ugly, no incidents |
| Better Stack | Unlimited/3min | $24/mo | Beautiful, incidents | Expensive |
| Freshping | 50/1min | ~$8/mo | 1-min free interval | Weak brand |
| Pingdom | None | $15/mo | RUM, established | Expensive, dated |
| StatusCake | Unlimited/5min | $24.49/mo | Unlimited free | Dated UI |
| Checkly | 5/10min | $80/mo | Dev-first, code | Not beginner-friendly |
| HetrixTools | 15/5min | $9.95/mo | White-label | Basic UI |

## Our Positioning: Beautiful + Affordable + Incident Management

Beat UptimeRobot on design. Beat Better Stack on price. Own the "modern monitoring for bootstrappers" niche.
